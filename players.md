# PLAYERS DATABASE INDEX

## 1. Overview
Dokumen ini memuat daftar direktori katalog pemain aktif dan file save resmi yang terdaftar di dalam direktori `players/`.

> **Aturan Admin**: File ini bersifat read-only bagi AI-GM selama gameplay berlangsung. AI-GM memanggil file spesifik pemain di folder `players/` hanya saat pertama kali karakter dimainkan.
