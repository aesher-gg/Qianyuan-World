# 🏮 Qianyuan-World — World Bible (Modular Repository Edisi Qianyuan)

**Versi**: 1.0
**Genre**: Xianxia · Wuxia · Kultivasi · Hardcore Realism
**Tujuan**: Menjalankan roleplay kultivasi yang adil, mendalam, konsisten, taktis, dan realistis bersama AI Game Master (AI-GM) tanpa perlu menyalin satu dokumen tunggal yang raksasa.

---

## 📂 Struktur Modul Repository

Repository Qianyuan-World diorganisasikan ke dalam file `.md` terstruktur sebagai berikut:

* **Navigasi Inti**: `INDEX.md` (Hub Navigasi Utama tempat seluruh link module terdaftar).
* **Aturan AI GM**: `00_CORE_RULES_AI_GM.md` (Aturan mutlak AI-GM, format respon wajib, dan cheat-sheet).
* **Gambaran Dunia & Ibu Kota**: `01_WORLD_OVERVIEW_AND_CAPITAL.md` (Nine Meridian Currents & Yuanjing).
* **Modul Wilayah (02–10)**: Modul geografis, ekologi Qi, dan bahaya regional.
* **Organisasi Lintas Wilayah**: `11_CROSS_REGION_ORGANIZATIONS.md`.
* **Sistem Game Inti (12–20)**: Kultivasi, Ekonomi, Vitalitas Tubuh, Pertarungan Taktis, Crafting, Profesi, Kebun Spiritual, Beast Bond, dan Bestiary.
* **Sekte Spesifik (21–30)**: 10 Sekte/Perguruan utama.
* **Kapal Udara Lingzhou**: `31_SPIRIT_AIRSHIP_SYSTEM.md`.
* **Konten Dinamis (32–35)**: Database Event, Laws, Sects, dan Techniques ciptaan pemain.
* **Database Pemain**: File `players.md` dan direktori `players/`.

## ⏳ Aturan Sesi & Save System

1. **Format Respon GM Wajib**: AI-GM menyajikan Narasi GM, Log Kalkulasi, Blok Profil Karakter Terkini, dan Pilihan Aksi.
2. **Sistem Save Karakter**: Salin blok Profil Karakter Terkini dari respon AI-GM di akhir sesi dan kirimkan ke Admin repository untuk disimpan di folder `players/<nama_karakter>.md`.
