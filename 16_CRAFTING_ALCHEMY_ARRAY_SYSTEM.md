# 16 — CRAFTING ALCHEMY ARRAY SYSTEM

## 1. Overview
Crafting Alchemy Array System adalah sistem produksi barang spiritual di Qianyuan-World yang mencakup penempaan senjata/zirah (*Forging*), pembuat obat/pil spiritual (*Alchemy*), penyusunan formasi pelindung/segel (*Formation*), dan pembuatan jimat kertas (*Talisman*). Hasil crafting tidak ditentukan hanya berdasarkan level karakter, melainkan oleh material, alat, teknik, dan lingkungan.

---

## 2. Core Production Disciplines

### 2.1 Forging (Penempaan)
* **Keluaran**: Senjata spiritual, zirah, pelindung tubuh, instrumen logam.
* **Faktor Kunci**: Kualitas Ore/Mineral, Kuantitas Panas Api Tempur, Keterampilan Penempa, Cetakan Formasi Senjata.

### 2.2 Alchemy (Pembuatan Pil & Obat)
* **Keluaran**: Dan-Pill (Pil Kultivasi, Pil Penyembuh, Pil Terobos), Cairan Obat, Penawar Racun.
* **Faktor Kunci**: Kesegaran Bahan Herba, Kuali Alkimia (*Cauldron Grade*), Pengendalian Api Spiritual (*Flame Control*), Urutan Racikan.

### 2.3 Formation (Formasi Spiritual)
* **Keluaran**: Formasi Pelindung Wilayah, Formasi Pengumpul Qi, Formasi Segel/Jebakan.
* **Faktor Kunci**: Batu Inti Formasi (*Formation Core*), Garis Ukiran Qi, Keseimbangan Elemen Lingkungan.

### 2.4 Talisman (Jimat Kertas Spiritual)
* **Keluaran**: Jimat Serang (Fireball/Lightning), Jimat Pelindung, Jimat Komunikasi, Jimat Kecepatan.
* **Faktor Kunci**: Kertas Jimat Spiritual, Tinta Darah Beast/Cairan Qi, Kuas Jiwa, Keakuratan Kaligrafi Segel.

---

## 3. Production Quality Grade
Hasil produk akhir dibagi menjadi 5 tingkatan kualitas:

1. **Defective / Flawed (Gagal / Cacat)**: Efek berkurang 50%, berisiko meledak/rusak saat digunakan.
2. **Common Grade (Standar)**: Efek normal 100%.
3. **Superior Grade (Berkualitas Tinggi)**: Efek +25% hingga +30%, durabilitas lebih kuat.
4. **Masterpiece Grade (Sempurna)**: Efek +50%, memiliki atribut bonus elemen.
5. **Heavenly Grade (Langka/Legendaris)**: Memiliki kesadaran روح (Spirit Soul) atau efek khusus tanpa tandingan.

---

## 4. Production Process & Risk
Kalkulasi keberhasilan pembuatan barang:

$$\text{Success Chance} = \text{Crafter Skill Level} + \text{Material Quality Bonus} + \text{Tool Grade} + \text{Environment Bonus} - \text{Recipe Complexity}$$

* **Kegagalan Alchemy**: Kuali Meledak (*Furnace Explosion*), bahan terbuang, pemicuan Miasma beracun.
* **Kegagalan Forging**: Logam retak/hancur, kehilangan energi Qi pada senjata.
* **Kegagalan Formation**: Formasi berbalik menyerang pembuat (*Backfire Shock*).

---

## 5. GM Instructions
* Tanyakan ketersediaan resep, bahan baku, dan fasilitas (kuali/tungku tempa) sebelum mengizinkan proses crafting.
* Lakukan kalkulasi risiko kegagalan jika pembuat mencoba membuat barang di atas tingkat keterampilannya.
